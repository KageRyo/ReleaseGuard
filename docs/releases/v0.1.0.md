# ReleaseGuard v0.1.0

Initial public release.

ReleaseGuard is a standalone dataset release gate for CI pipelines. It validates CSV structure, relationships, temporal constraints, and file integrity before release.

Features:

- Declarative `release.yaml`
- CSV schema and primitive type validation
- Nullable field validation
- Unique constraints
- Foreign-key validation
- Temporal-order validation
- Cross-file temporal joins
- Deterministic SHA-256 release manifests that cover `release.yaml` and configured dataset files
- Text and JSON output
- CI-friendly exit codes
- Standalone binaries for Linux x86_64, Windows x86_64, and macOS arm64
