# ReleaseGuard v0.2.0

ReleaseGuard adds a pinned GitHub Actions integration while retaining the standalone CLI and all three platform archives.

- Use `KageRyo/ReleaseGuard@v0.2.0` with a dataset `path` to run validation in a GitHub Actions job.
- The Action downloads the matching Linux x86_64 CLI release and verifies its archive with `SHA256SUMS` before execution.
- The Action and CLI release versions are checked together by the release workflow.
- The Action currently supports Linux x86_64 runners and the `validate` command. Standalone binaries remain available for Linux x86_64, Windows x86_64, and macOS arm64.
