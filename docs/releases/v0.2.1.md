# ReleaseGuard v0.2.1

This patch release prepares the GitHub Actions integration for Marketplace publication with a unique action name and metadata branding. The standalone CLI and validation behavior are unchanged.

- Action name: `ReleaseGuard Dataset Validator`.
- Use `KageRyo/ReleaseGuard@v0.2.1` with a dataset `path` to run validation in a GitHub Actions job.
- The Action downloads the matching Linux x86_64 CLI release and verifies its archive with `SHA256SUMS` before execution.
