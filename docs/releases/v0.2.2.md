# ReleaseGuard v0.2.2

This patch release ships the maintained YAML parser already used on `main` in the standalone binaries and the GitHub Action. The CLI commands, dataset schema, validation behavior, and exit codes are unchanged.

- Replace the deprecated `serde_yaml` runtime dependency with `yaml_serde 0.10.7`.
- Use `KageRyo/ReleaseGuard@v0.2.2` with a dataset `path` to run validation in a GitHub Actions job.
- The Action downloads the matching Linux x86_64 binary and verifies its archive against `SHA256SUMS` before execution.
- Provide Linux x86_64, Windows x86_64, and macOS arm64 archives, each including the executable and license notices.
- Check tag, package, and Action version consistency before release builds, and validate the published Action against the basic dataset fixture.
