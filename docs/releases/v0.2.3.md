# ReleaseGuard v0.2.3

This security patch prevents manifest generation from truncating another file through a hard-linked manifest path. Generated manifests now use exclusively created temporary files and atomic replacement; existing symlink rejection remains in place.

Output permissions retain normal umask-derived defaults and existing regular-file permission modes. Manifest bytes, dataset validation, checksum semantics and exit codes are unchanged.

Use `KageRyo/ReleaseGuard@v0.2.3`. The Action verifies the matching Linux archive against `SHA256SUMS`. Release archives cover Linux x86_64, Windows x86_64 and macOS arm64 and include license notices.
